# Uzunguni premium UI demo

Interactive customer payment and staff dashboard prototype based on the Uzunguni City Park mockups.

## Run locally

```powershell
npm.cmd install
npm.cmd run dev
```

Open http://localhost:3000 for the customer payment flow or http://localhost:3000/staff for the staff dashboard.

This is a frontend demonstration only. It does not accept real payments or store a real customer bill.
